# A Federated Hybrid Intrusion Detection Framework for Energy-Efficient and Low-Latency Edge IoT Networks

## Overview

This repository contains the implementation and experimental resources associated with the research paper *A Federated Hybrid Intrusion Detection Framework for Energy-Efficient and Low-Latency Edge IoT Networks*.

The proposed framework integrates a hybrid CNN-LSTM-Attention intrusion detection model with federated learning, cross-dataset adaptation, and an energy-latency-aware scheduling mechanism for Edge IoT environments.

## Key Components

- **Hybrid Intrusion Detection:** CNN, LSTM, and Attention-based architecture.
- **Federated Learning:** Privacy-preserving distributed training using FedAvg aggregation.
- **Cross-Dataset Adaptation:** Transfer learning-based evaluation under dataset shifts.
- **Tier-Aware Scheduling:** Simulation-based task allocation across local, edge, and cloud resources.
- **Performance Evaluation:** Classification, federated learning, and scheduling metrics.
